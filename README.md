Welcome to Mel's To Do List Program.

This is a terminal based program that is best experienced in IDEs like VSCode, but can also be utilized in Windows Powershell and Terminal.

Please start by downloading all of the .java files into a folder of your choosing to be able to utilize the program effectively. Nest these files within their own folder within that folder and name the program folder "ToDoList" for the program to work effectively. The outer folder that you made will catch your save files. Open this file path utilizing your terminal or IDE. When you're ready, please start the program by calling upon the ToDoListMain.java program file.

Please note that you will have to download the latest version of JDK to run this program. Please find it from the source website in order to download it. The VSCode IDE made this integration process relatively painless for me.
